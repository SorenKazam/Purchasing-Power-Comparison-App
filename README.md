# 💸 Purchasing Power Comparison App

This is a small and practical web app that compares how much a product costs *in terms of salary* between two countries. It helps visualize the **purchasing power** required to buy the same product in different economies 🌍.

## 📊 What It Does

You enter:

- 🏠 The minimum salary and product price in **your country**
- ✈️ The minimum salary and product price in **another country**

And the app calculates:

- How much % of the minimum wage the product represents in **each country**
- Two progress bars show the comparison visually ✔️

For example:

> A product that costs €100 in a country where the minimum wage is €1000 = **10%** of the salary  
> The same product costing $80 in another country with $400 minimum wage = **20%** of the salary  
> → This means the product is **twice as expensive** (relatively) in the second country!

## 🧠 Why This Is Useful

This tool can help:

- People moving abroad or planning to travel
- Compare cost of living between countries
- Understand global economic inequalities

## 🚀 How To Use

1. Open `index.html` in any browser (no setup needed)
2. Enter salary and product price info
3. Click **"Calcular"**
4. View the results and the visual comparison

## 🛠️ Technologies

- **HTML** + **CSS** + **JavaScript** (Vanilla)
- Fully client-side, no backend or database

## 📂 Files

- `index.html` → The main interface  
- `style.css` → Simple and clean styling  
- `scripts.js` → Logic that calculates the percentages and updates the UI
